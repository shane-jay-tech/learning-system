## 三、height=240 是否需要档位化：结论＝**不需要**，三条依据

`grep -n "height=240" ui/pages/dashboard.py` → **仅 1 处命中：`:111`**（已列入 §二 第 6 行）。
全 `ui/` 里其余 `height=` 只有编辑器/文本域（`ui/components.py:94`、`ui/pages/language.py:268/412/478/532`），与首屏图高无关。

**(a) 结构上本仓没有「纵向档位」的承接机制。**
`ui/styles.py` 三个断点全按**宽度**判（`:5` 1280、`:6` 900、`:318` 1000），
全档 `grep -n "max-height" ui/styles.py` 只有 `:259` 的 `.io-box { max-height: 240px; overflow:auto }`——那是滚动盒，**不是 `@media (max-height:)`**；
`ui/` 亦零 JS/自定义组件（`grep "components.html\|<script\|innerHeight" ui/` 0 命中）。
⇒ `st.bar_chart(height=…)` 是 Python 侧常量，**运行时看不到浏览器 innerHeight**，「按 768 高换档」不是改 CSS 能实现的，得先新增视口输入通道（属新机制，非样式微调）。

**(b) 收益上：砍图高换不来「多露一节」。** 敏感性推演（同脚本 `sweep()`，老用户态）：

| height | 768 视口折在第几节 | 图底绝对位置 | 现实 ~600 视口 |
|---|---|---|---|
| 240（现状） | 第 7 行「§各语言标题」 | 705 | 拦腰 105px |
| 200 | 第 8 行「5 语言卡」中部 | 665 | 拦腰 65px |
| 180 | 第 8 行「5 语言卡」中部 | 645 | 拦腰 45px |
| 160 | 第 8 行「5 语言卡」中部 | 625 | 拦腰 25px |
| 140 | 第 8 行「5 语言卡」中部 | 605 | 拦腰 5px |
| 135 | — | 600 | 恰好容纳（下限） |

⇒ 名义 768 下从 240 一路砍到 140，只多露 **一个标题**（第 7 行→第 8 行了也仍看不见卡）；
现实 600 视口下**任何 ≥140 的档位都会被拦腰**，档位化既解决不了它、又把「14 天趋势」这个面板页主表达压到不可读。

**(c) 预算大户不是它。** 首屏前 4 块（顶距 32＋hero 139＋趋势标题 59＋指标卡 96＝**385px，占 768 的 50%**）才是折叠线的位置决定项；
全页 13 个 `section_title` × 58.8px ＝ **≈765px＝一整个首屏花在纯标题上**（`.section-title margin: 1.8rem 0 .75rem`，`ui/styles.py:137`）；
两条长尾「成就 705 ＋ 最近活动 778」＝ 1483px，占全页 31%，把导出区顶到 3657px。

## 五、必须靠浏览器实测校准的 4 个假设点（本档结论的不确定度来源）

1. **主块垂直 gap＝1rem**：未在本仓覆写，取 Streamlit 同族默认——`streamlit/elements/layouts.py:224`（container）与 `:440`（columns）均写 `"small" (default): 1rem`。25 块 ≈ 24×16＝384px 全押在这个值上。
2. **Streamlit header 是否占高**：本仓只把 `header[data-testid="stHeader"]` 背景改透明（`ui/styles.py:282`）**未 `display:none`**；若该栏仍占 56px，则 §二 全部累计值需整体下移，名义 768 的余量 63px 会**直接变成超界 7px**——这条最可能翻盘。
3. **容器内边距 2×16／st.metric 实际行盒**：`LANG_ROW`、`RECO_CARD` 用 32px 内边距与 `1.72` 行高（`ui/styles.py:55-57`）估，误差 ±10px/块。
4. **徽章描述是否折行**：`ACH_BADGE` 按描述折两行估（104px/枚）；若单行则 6 行降至 ~88px/枚，成就区少 ~100px。

另：**「现实视口 600px」本身是推演者估设**（无实测），日间批请直接在 1366×768 屏上量 `window.innerHeight` 一次替换该列。
