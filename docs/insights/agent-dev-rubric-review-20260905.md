# agent_dev 开放题 rubric 评分设计质量评审（只评不改，2026-09-05 夜 1022）

> 对象：audit_content_deep 五条 warning 中的两条——`agent_dev/12_spec_iteration` 与 `agent_dev/13_multi_round` 各 5 道 `judge_mode: ai_open` 开放题（无 reference_answer 属有意设计）。
> 判卷实现依据：`core/judge.py::_judge_open` → `core/ai_review.py::grade_open_answer`（prompt = 题干≤1500 字 + rubric≤1500 字 + 学生回答；LLM 返回 JSON {passed, score 0-100, feedback, dimensions[]}，score 被夹到 0-100）。
> 声明：content/ 与 core/ 零改动（git status 干净后仅新增本报告）。

## 〇、总体结论

10 份 rubric 是**同仓里质量上乘的一档**：分值全部恰好凑 100（与 judge 的 0-100 归一天然吻合）、长度远低于 1500 截断线、多数评分点用了可判定的行为动词、题干要求与评分项大体 1:1 映射。共性问题集中在四处（见第三节），三题有必修级错位（12-01 / 13-02 / 13-05）。

## 二、改进草案（staging，不落库；9 题）

- **12-01（必修）**：题干改「找出尽可能多的问题（共5类线索，满分需≥5）」或 rubric 明示「找出4类封顶80分」；第6项拆「格式符合（问题+后果分段）」与「后果与问题对应」两小项。
- **12-02**：追加第7项「重写后的 Spec 可直接交付 Agent 执行（无『等/之类』模糊词）」10 分，压其余项至 90 内重配。
- **12-03**：第6项操作化——「第三方可照做：无歧义代词、每条指令含目标文件/行为/验收」。
- **12-04**：删除第6项，其 15 分并入第4项「理由」（改 35 分，注明部分给分口径：全对35/部分20/弱10）。
- **12-05**：维持；仅建议第4项把「等」换成「至少覆盖：文件大小、生成超时、文件名」三选二。
- **13-01**：第5项枚举化——「验收含：新注册部门必填且入库 / 老用户部门为空不报错 / 下拉四选项含空态」。
- **13-02（必修）**：第1项改为「根因表述指向『统一分页状态数据源』方案而非复述现象（20分）」；另加「要求 Agent 输出读取分页参数的完整模块清单作为验证物」并入第4项。
- **13-04**：第5项结构化——「回复含三分类清单（做/不做/延后）+ 每项一句理由 + 下一步动作」；第7项附证据锚「在判断标准中可引用『是否解决当前用户核心问题』类准则」。
- **13-05（必修）**：第2项扩为「v1/v2/v3 各有≥1条可验证验收标准（15分）」，从第7项匀 5 分。

## 三、共性问题（4 条）

1. **抽象原则项难机械判定**：6/10 题各有一个「体现了X原则/理解Y核心」类抽象项，判卷模型只能凭整体印象打分，且常与具体项重复计分（12-04#6 最典型）。
2. **题干与 rubric 双向对账缺失**：题干显式要求未必有评分项（13-05 三版验收只评 v1），评分项也未必被题干要求（12-01 第5类问题超出「至少4个」承诺）。
3. **题干已给信息设复述分**：13-02 根因 20 分实为抄题分，零区分度。
4. **风格/语气项主观**：13-04「友好但坚定」无观察标准，LLM 打分不稳定。

正面共性（保持）：分值和恒为 100、单项 10-20 分、rubric 长度 200-400 字符（截断线 1500 的 1/5）、多题含「超出清单的加分洞察项」（12-03#5、13-01#3/#4）是很好的区分度设计。

## 四、rubric 编写规范建议（给后续出题）

- **R1 行为动词+可观察产物**：「写出了≥2条可验证验收标准」，禁「清晰/深入/合理」裸用。
- **R2 双向对账**：定稿前逐条核对「题干每个显式要求 ↔ 评分项」双向覆盖；超出题干的评分项须在题干加「满分线索」提示。
- **R3 抽象项必须带证据锚**：写明判卷可引用的文本特征（如回复含三分类清单）。
- **R4 不给复述分**：题干已提供的信息（根因、背景）不设识别分；评分点指向增量产出。
- **R5 部分给分口径显式化**：多元项注明 全有/部分/无 三档分值，降低 LLM 自由裁量。
- **R6 风格项转结构项**：语气要求改写为清单/格式要求。
- **R7 机械约束**：分值和=100、单项≥5 分、rubric ≤800 字符（留截断余量）、行为动词开头。
