# 数据安全与隐私：碰真人数据前必须懂的事

只要你的工具碰**真实的人的数据**——尤其像心理调查、员工问卷这种——你就有了一份责任：别让这些数据泄露、别拿它干超出授权的事。这一章不教写代码，教**判断力**：什么数据敏感、什么操作危险、怎么做才稳妥。

## 三个核心概念

**1. PII（个人可识别信息）**
能直接或间接认出"这是谁"的信息。
- **直接标识**：姓名、手机号、身份证号、邮箱、人脸
- **准标识**：单看不认人，但**组合起来**能锁定——比如"出生日期 + 邮编 + 性别"三者一起，往往能唯一定位一个人

**2. 数据最小化**
只收集 / 只保留你**真正需要**的数据。分析部门平均敬业度，根本不需要员工姓名——那就别收。收得越少，泄露的风险越小。

**3. 匿名化 vs 假名化**
- **假名化**：把姓名换成 `员工001`，但你还留着一张"对照表"能还原 → 还是 PII
- **匿名化**：彻底删掉标识、聚合到组，**没人能还原** → 才算真的脱敏

## 两条铁律

- **密钥/密码绝不写进代码**：API key、数据库密码硬编码进 `.py`，一旦提交到 Git、写进日志、或把代码发给别人，就泄露了。正确做法：放环境变量或 `.env` 文件，且 `.env` 不进版本库。
- **原始数据和分析结果分开**：能用聚合结果（部门平均分）就别动个人原始记录。

这些判断，做错一次就可能伤到真实的人。所以这章的题没有"标准代码"，AI 老师会看你**想得够不够周全**。
