# 读懂代码：比会写更值钱的能力

对你来说，**读代码比从零写代码更重要**。你跟 AI 协作时，AI 给你一段代码，你得能看懂它在干嘛、判断对不对、发现哪里有坑——这才是"系统拥有者"真正用得上的能力。

写代码可以交给 AI，但**判断代码对不对，得靠你自己**。

## 读代码的三个层次

1. **它在干嘛**：一句话说清这段代码的目的（不是逐行翻译，是抓主干）
2. **它怎么干的**：数据怎么流动、关键步骤是什么
3. **它哪里可能出问题**：空输入？边界？特殊值？——资深的人读代码时脑子里always在想"什么情况会让它崩"

## 几个常见的"坑"，读代码时要警觉

- **可变默认参数**：`def f(x, acc=[])` —— 这个 `[]` 只创建一次，会在多次调用间共享，是经典陷阱
- **边界**：空列表、除以零、索引越界、`None`
- **off-by-one**：`range` 和切片差一位
- **静默错误**：`except: pass` 把问题藏起来

这一章的题，AI 老师会看你**读懂了没、想得周不周全**——没有标准代码答案，重点是你的理解和判断。
