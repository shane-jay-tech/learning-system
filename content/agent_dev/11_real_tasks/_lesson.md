# 真实任务包：综合实战

这一节把前面学到的所有 Agent 协作技能串起来，用**接近真实开发的场景**考你。

## 和真实开发有什么不同？

在真实项目里，你不是"做一道题"——你面对的是：
- 一段你没见过的代码（可能几百行）
- 一个不太清晰的需求（"这个按钮不好用"）
- 一条看不太懂的报错（`TypeError: cannot unpack non-iterable NoneType object`）

你要做的不是自己写代码，而是**指挥 AI agent 去修**。

## 核心循环

```
发现问题 → 定位范围 → 写清楚指令 → 让 agent 干 → 审结果 → 反馈修正
```

每一步都有对应技能：
- 发现问题 = 读代码 + 调试日志
- 定位范围 = 任务拆解
- 写清楚指令 = Spec 写作
- 审结果 = Code Review
- 反馈修正 = 迭代沟通

## 这一节的题目

都是开放题，没有标准答案——AI 老师按评分标准（rubric）打分。
写得越具体、越可执行，得分越高。
