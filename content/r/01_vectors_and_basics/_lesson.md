# 向量与基础运算

## R 是什么

R 是 **统计学家专用** 的编程语言。学术界做实验数据分析、生物信息学跑基因序列、金融行业做量化模型、市场调研做问卷分析——这些场景里 R 都是常客。它的特长是 **数据处理 + 可视化**：几行代码就能画出论文级别的图表。

R 跟 Python 风格上有几个明显不同：

- 用 `<-` 而不是 `=` 做赋值（虽然 `=` 也能用，但社区习惯 `<-`）
- 一切都是"向量"——单个数字也是长度为 1 的向量
- 大量函数已经针对"批量数据"做了优化，写循环少很多

## 输出文字：cat 和 print

R 里有两种常用的"打印"方式：

```r
cat("Hello, World!\n")     # 直接输出，需要自己写 \n 换行
print("Hello, World!")     # 自动换行，但前面会加 [1]
```

两者的差别看一下输出对比：

```
cat:    Hello, World!
print:  [1] "Hello, World!"
```

`[1]` 是 print 给你的"向量下标提示"——它在告诉你"从第 1 个元素开始显示"。在做练习题时，**期望输出是不带 `[1]` 的，所以一律用 `cat`**。

## 赋值：箭头 `<-`

```r
x <- 10
name <- "小明"
score <- 92.5
```

也可以反向写 `10 -> x`，但这种写法不常见。键盘上 `<-` 在 RStudio 里有快捷键 `Alt + -`。

## 向量：c() 是入门钥匙

R 里几乎一切运算都是"对一组数同时做"。这"一组数"就叫向量，用 `c()` 函数构造：

```r
v <- c(3, 5, 7, 9, 11)
```

向量的好处：你可以一次对所有元素做运算，不用写循环：

```r
v + 1        # 每个元素都加 1，得到 c(4, 6, 8, 10, 12)
v * 2        # 每个元素都乘 2
sum(v)       # 求和，得到 35
mean(v)      # 求平均值，得到 7
length(v)    # 元素个数，得到 5
max(v) ; min(v)
```

## 把结果输出来

把向量的计算结果用 `cat` 打印出来：

```r
v <- c(3, 5, 7)
cat(sum(v), "\n")     # 输出 15
cat("平均：", mean(v), "\n")  # 输出 平均：5
```

`cat` 接受任意个参数，默认用空格分隔。最后那个 `"\n"` 是手动换行符，**几乎所有 cat 调用都需要它**，否则下一行会粘到这行后面。

## 向量索引：从 1 开始（注意！）

```r
v <- c(3, 5, 7, 9, 11)
v[1]      # 第 1 个元素，3（不是 5！）
v[3]      # 第 3 个元素，7
v[1:3]    # 前 3 个，c(3, 5, 7)
```

⚠️ R 的索引 **从 1 开始**，不是 0。这一点和 Python、C++ 都不同。

## 注释和大小写

- 注释用 `#`，从 `#` 到行尾都被忽略
- 大小写敏感：`Sum(v)` ≠ `sum(v)`（前者会报错"找不到 Sum"）
- 函数名习惯小写 + 下划线

## 新手常见错误

1. **忘了 `\n`**：`cat("结果：", x)` 不会换行，下次输出就会粘上来
2. **用 print 写练习题**：会带 `[1]` 前缀，导致输出和期望不匹配
3. **大小写错了**：`Cat`、`SUM` 都不是 R 自带的函数
4. **赋值用 `==`**：`x == 5` 是 **比较** 不是赋值；赋值用 `<-` 或 `=`
