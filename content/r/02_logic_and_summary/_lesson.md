# 逻辑判断与数据汇总

## 这一节学什么

R 的杀手锏是**对一组数据一次性算个统计**。这一节把基础工具讲齐：

- `ifelse()` 向量化的条件判断
- `mean / median / sd / var` 一组常用统计函数
- `which.max / which.min` 找最大最小**位置**
- 逻辑向量做条件筛选

## ifelse：向量化的 if

普通的 `if` 一次只能判断一个值：

```r
x <- 7
if (x %% 2 == 0) {
    cat("even\n")
} else {
    cat("odd\n")
}
```

但 R 的特长是处理**一整个向量**。`ifelse(条件, 真时取这个, 假时取这个)` 能对每个元素分别判断：

```r
v <- c(3, 8, 5, 12, 7)
parity <- ifelse(v %% 2 == 0, "even", "odd")
# parity = c("odd","even","odd","even","odd")
```

## 统计函数：基础工具箱

```r
v <- c(3, 5, 7, 11, 14)
mean(v)     # 平均值 8
median(v)   # 中位数 7
sd(v)       # 标准差
var(v)      # 方差
sum(v)      # 总和 40
length(v)   # 个数 5
range(v)    # 最小最大值 c(3, 14)
```

## 找最大值的"位置" vs "值"

| 想要什么 | 用什么 |
|---|---|
| 最大**值** | `max(v)` |
| 最大值的**位置**（下标） | `which.max(v)` |
| 最小**值** | `min(v)` |
| 最小值的**位置** | `which.min(v)` |

```r
v <- c(20, 50, 30, 80, 10)
max(v)         # 80
which.max(v)   # 4（80 在第 4 位）
```

⚠️ R 的下标 **从 1 开始**，所以 `which.max` 返回的是"第 N 个"而不是"位置 N-1"。

## 逻辑向量与条件筛选

```r
v <- c(3, 5, 7, 11, 14)
v >= 7              # c(FALSE, FALSE, TRUE, TRUE, TRUE)
sum(v >= 7)         # 3（TRUE 当作 1，FALSE 当作 0）
v[v >= 7]           # c(7, 11, 14) —— 用逻辑向量做筛选
mean(v[v >= 7])     # 10.67 —— 大于等于 7 的元素的平均数
```

把 `>=` 比较的结果直接 `sum()`，相当于**数有多少个 TRUE**。这是 R 里特别简洁的一个习惯用法。

## cat 配合多个值

`cat` 输出多个值时会**自动用空格分隔**：

```r
v <- c(3, 5, 7)
cat("总和：", sum(v), " 平均：", mean(v), "\n")
# 输出：总和： 15  平均： 5
```

注意空格：`"总和："`后面的 ` ` 和 cat 自动加的空格会重叠成两格。如果想要紧凑，用 `sep`：

```r
cat("总和=", sum(v), sep="")
cat("\n")
```

`sep=""` 表示参数之间不要分隔符。

## 常见错误

1. **用 `==` 比较向量**：`v == c(3,5,7)` 是逐元素比较，不是判断"两向量是否相等"——用 `identical(v, c(3,5,7))`
2. **`mean()` 遇到 NA**：默认会返回 NA。用 `mean(v, na.rm=TRUE)` 跳过缺失值
3. **`length()` 用错对象**：`length("hello")` 返回 1（一个字符串当作一个元素），要数字符数用 `nchar()`
