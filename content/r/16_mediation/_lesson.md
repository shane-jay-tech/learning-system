# 中介效应分析

检验"A 通过 B 影响 C"的间接效应，是心理学论文中"机制解释"部分的标准方法。

## 为什么重要

你发现领导风格影响员工离职意向（X → Y），但"为什么"？可能是领导风格先影响了工作满意度（X → M），满意度再影响离职意向（M → Y）。中介分析就是检验这个"通过什么路径起作用"的问题。

## 核心概念

- **中介模型**：X → M → Y（M 是中介变量）
- **直接效应**：X → Y（控制 M 后）
- **间接效应**：X → M → Y（a × b 路径）
- **完全中介**：加入 M 后直接效应不显著
- **部分中介**：加入 M 后直接效应变小但仍显著

## 最小示例

```r
library(lavaan)
med_model <- '
  M ~ a*X
  Y ~ b*M + c*X
  indirect := a*b
  total := a*b + c
'
fit <- sem(med_model, data = mydata, bootstrap = 5000)
parameterEstimates(fit, boot.ci.type = "perc")
```

## 检验方法

- **Bootstrap 法**（推荐）：不假设正态分布，置信区间不含 0 即显著
- **Sobel 检验**（旧方法）：假设正态分布，小样本不推荐
- **报告格式**：间接效应 = 0.15, 95% CI [0.08, 0.24]，不含 0，中介效应显著

## 做题前检查

1. 理论上中介路径是否合理（不能纯靠数据驱动）
2. Bootstrap 次数设为 5000（最少 1000）
3. 看百分位置信区间（`boot.ci.type = "perc"`）
4. 报告直接效应、间接效应和总效应

## 常见错误

- 把中介变量和调节变量搞混（中介是"通过什么"，调节是"什么条件下"）
- 样本太小做 Bootstrap（N < 100 结果不稳定）
- 忘记检查变量间基本相关（如果 X-M 或 M-Y 都不相关，没必要做中介）
