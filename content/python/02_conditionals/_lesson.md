# 条件判断（if / elif / else）

## 程序为什么需要"判断"

到目前为止你写的 Python 都是"从上往下一行一行跑"。但真实程序经常要根据**当前情况**做不同的事——成绩 ≥60 才"及格"，余额够才能扣款，年份能被 4 整除才是闰年。这就是 **条件判断**。

## if 的基本写法

```python
score = 75
if score >= 60:
    print("及格")
```

注意三个细节：

1. **冒号** `:` 不能少——它告诉 Python "下面是条件成立时要做的事"
2. **缩进** 必须有，且整段一致（建议 4 个空格）。Python 用缩进代替 `{ }`
3. 条件本身是一个能判断 **真假** 的表达式

## if + else：二选一

```python
score = 55
if score >= 60:
    print("及格")
else:
    print("不及格")
```

## if + elif + else：多分支

```python
score = 85
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 60:
    print("C")
else:
    print("D")
```

`elif` 是 "else if" 的缩写。Python 从上到下依次试，**第一个**成立的分支被执行，后面的全跳过。

## 比较运算符

| 符号 | 含义 |
|---|---|
| `==` | 等于（不是 `=`！） |
| `!=` | 不等于 |
| `>`, `<` | 大于、小于 |
| `>=`, `<=` | 大于等于、小于等于 |

⚠️ 最常见错误：把 `==` 写成 `=`。`=` 是赋值（"放进盒子"），`==` 是比较（"两个值相等吗"）。

## 逻辑运算符：把多个条件拼起来

```python
age = 20
license = True
if age >= 18 and license:
    print("可以开车")
```

| 关键字 | 含义 | 例子 |
|---|---|---|
| `and` | 且：两边都要为真 | `x > 0 and x < 10` |
| `or`  | 或：任一为真即可 | `day == "Sat" or day == "Sun"` |
| `not` | 非：取反 | `not is_holiday` |

## 取余 `%` 在判断中很常用

判断"能否被 N 整除"：

```python
n = 12
if n % 2 == 0:
    print("偶数")
else:
    print("奇数")
```

`%` 是取余运算，`12 % 2` 等于 `0`，所以 12 是偶数。

## 常见错误

1. **冒号忘了**：`if x > 0` 后面缺 `:`，立刻报 SyntaxError
2. **缩进不一致**：if 块里用 4 空格，下一行用 2 空格 → IndentationError
3. **`if x = 5`**：这是赋值不是比较；要写 `if x == 5`
4. **else 后面加条件**：`else x > 0:` 是错的；要么 `else:` 要么 `elif x > 0:`
