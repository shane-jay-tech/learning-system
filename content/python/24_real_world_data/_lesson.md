# 真实世界的数据：又脏又乱才是常态

前面的 pandas 题用的都是干净的小表。但**真实工作里的数据从来不干净**——尤其做 People Analytics（人力数据分析）时，你拿到的调查表往往是这样的：

- **缺失值**：有人没填评分，单元格是空的
- **重复行**：同一份问卷被提交了两次
- **分类不统一**：部门一会儿写 `Sales`、一会儿 `sales `（带空格）、一会儿 `HR`、`hr`
- **缺失的数值**：入职月数没填

这一章用一份**模拟的员工敬业度调查**练真功夫：先清洗，再统计。这正是数据分析师每天在干的事——**80% 的时间在清洗，20% 在分析**。

每道题的 starter code 已经帮你把这份脏数据加载成 `df`，你只需要专注写"清洗 + 分析"的逻辑。

几个关键武器：
- `df.isna().sum()` —— 数缺失值
- `df.drop_duplicates()` —— 去掉完全重复的行
- `df["列"].str.strip().str.title()` —— 规范文本（去空格 + 首字母大写）
- `df.dropna(subset=["列"])` —— 删掉某列缺失的行
- `df.groupby("列")["数值列"].mean()` —— 分组求平均

记住：**清洗的顺序会影响结果**，想清楚先做哪步。
