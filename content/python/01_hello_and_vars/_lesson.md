# Hello World 与变量

## 为什么从 Python 开始

Python 是当今最受欢迎的编程语言之一。它的语法接近自然英语，几乎不需要写"花架子"，写一行就能跑起来。它在数据分析、人工智能、网站开发、办公自动化、爬虫等场景里都是首选工具。对于零基础的你，从 Python 入手的好处是 **见效快**——你今天写的第一行代码，明天就能在 Excel、数据图表、文件批处理这些真实任务里派上用场。

## 第一行代码：print 函数

`print` 是 Python 内置的输出函数，它把括号里的内容打印到屏幕上。

```python
print("你好，世界！")
```

几个要点：

- **括号** `()` 不能省略——括号代表"调用一个函数"
- 文字（专业一点叫"字符串"）必须用 **引号** 括起来；单引号 `'...'` 和双引号 `"..."` 都行，只要左右配对
- 末尾不需要分号——Python 用 **换行** 作为一句话的结束

## 变量是什么

变量就像贴了标签的盒子，你把数据放进去，下次按标签取出来用。

```python
name = "小明"
age = 18
score = 95.5
```

`=` 是 **赋值** 符号（不是数学里的"等于"）。它的意思是"把右边的值放进左边的盒子里"。变量名你可以自由起，规则只有三条：

1. 用英文字母、数字、下划线 `_` 组成
2. 不能以数字开头（`1name` ✘，`name1` ✓）
3. 区分大小写（`Name` 和 `name` 是两个不同的变量）

## 让变量参与计算

变量不是死的，它能参与计算：

```python
a = 3
b = 5
c = a + b      # c 现在是 8
print(c)       # 屏幕上显示 8
```

Python 支持的基本运算符：

| 符号 | 含义       | 例子           |
|----|----------|--------------|
| `+`  | 加        | `3 + 5` → `8`  |
| `-`  | 减        | `10 - 4` → `6` |
| `*`  | 乘        | `2 * 6` → `12` |
| `/`  | 除（带小数） | `7 / 2` → `3.5`|
| `//` | 整除      | `7 // 2` → `3` |
| `%`  | 取余      | `7 % 2` → `1`  |
| `**` | 幂        | `2 ** 3` → `8` |

## print 多个内容

`print` 可以一次打印多个东西，用逗号隔开会自动加一个空格：

```python
print("a + b =", a + b)   # 输出：a + b = 8
```

## 新手最常踩的三个坑

1. **引号忘了配对**：`print("Hello)` 会报错，因为缺右引号
2. **变量名打错**：`Pirnt(...)` 会被告知"找不到 Pirnt"——Python 区分大小写，而且严格按你写的字面找
3. **冒号后面忘了缩进**（暂时还没接触到，但要早知道）：Python 用空格缩进表示代码块，这点跟其它语言不一样
