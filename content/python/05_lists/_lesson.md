# 列表（list）

## 列表是什么

到现在你只用过单个变量装单个值（一个数、一个字符串）。但真实数据通常是 **一组**：5 个学生的分数、10 个文件的名字、本周每天的步数。**列表** 就是把一串值装在一起的容器。

```python
scores = [85, 92, 78, 88, 95]
names = ["Alice", "Bob", "Cathy"]
mixed = [1, "two", 3.0, True]   # 元素可以混搭，但通常不建议
empty = []                       # 空列表
```

方括号 `[]` + 元素之间逗号分隔。

## 索引：按位置取

Python 列表 **下标从 0 开始**：

```python
v = [10, 20, 30, 40, 50]
v[0]    # 10（第一个）
v[2]    # 30
v[-1]   # 50（负数从右往左数）
v[-2]   # 40
```

⚠️ 越界会抛 `IndexError`。比如 `v[10]` 在长度 5 的列表上就报错。

## 切片：取一段

```python
v[1:4]    # [20, 30, 40] —— 从下标 1 取到 4，不含 4
v[:3]     # [10, 20, 30] —— 从头取 3 个
v[2:]     # [30, 40, 50] —— 从下标 2 取到尾
v[::-1]   # [50, 40, 30, 20, 10] —— 反转！
v[::2]    # [10, 30, 50] —— 步长 2
```

切片是 **左闭右开**——`v[1:4]` 不含下标 4。

## 修改列表

| 操作 | 效果 |
|---|---|
| `v.append(x)` | 末尾加一个 |
| `v.insert(i, x)` | 在下标 i 插入一个 |
| `v.pop()` | 拿走并返回末尾元素 |
| `v.pop(i)` | 拿走并返回下标 i 的元素 |
| `v.remove(x)` | 删第一个等于 x 的元素 |
| `v[i] = x` | 直接覆盖下标 i 的位置 |

```python
v = [1, 2, 3]
v.append(4)        # [1, 2, 3, 4]
v[0] = 99          # [99, 2, 3, 4]
last = v.pop()     # last=4, v=[99, 2, 3]
```

## 常用全局函数

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]
len(nums)    # 8
sum(nums)    # 31
max(nums)    # 9
min(nums)    # 1
sorted(nums)            # 升序新列表 [1, 1, 2, 3, 4, 5, 6, 9]
sorted(nums, reverse=True)  # 降序
nums.sort()  # 原地排序，会改 nums 本身
```

`sorted(...)` 返回**新列表**，原列表不变；`nums.sort()` 直接改原列表。

## for 循环遍历

```python
for x in [10, 20, 30]:
    print(x * 2)
# 输出：20 40 60
```

不需要下标的话直接 `for x in v` 是最简洁的写法。需要下标用 `enumerate`：

```python
for i, x in enumerate(["a", "b", "c"]):
    print(i, x)    # 0 a / 1 b / 2 c
```

## 列表推导式（list comprehension）

Python 最优雅的写法之一——**用一行造一个新列表**：

```python
squares = [x * x for x in range(1, 6)]    # [1, 4, 9, 16, 25]
evens = [x for x in range(20) if x % 2 == 0]   # 只留偶数
upper = [s.upper() for s in ["a", "b"]]   # ["A", "B"]
```

模板：`[表达式 for 变量 in 序列 if 条件]`，`if` 部分可省。

## in 判断成员

```python
"Alice" in ["Alice", "Bob"]    # True
99 in [1, 2, 3]                # False
```

## 常见错误

1. **下标从 0 开始**——第一个是 `v[0]` 不是 `v[1]`
2. **越界**：`v[len(v)]` 错；应该是 `v[len(v)-1]` 或 `v[-1]`
3. **混淆 `append` 和 `+`**：`v.append([1,2])` 把列表当一个元素加进去；`v + [1,2]` 才是合并
4. **sort 没返回值**：`x = v.sort()` 让 x = None；要新列表用 `x = sorted(v)`
5. **遍历时改列表**：`for x in v: v.append(x)` 会无限循环——遍历期间不要改列表
