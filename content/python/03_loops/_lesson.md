# 循环（for / while）

## 程序为什么需要循环

到现在你写的代码每行只跑一次。但真实任务里很多事是 **重复性** 的：

- 把 1-100 全打印出来——你不可能写 100 行 print
- 数一数文件夹里有多少个 `.xlsx`——一个文件一个文件数太蠢
- 算 1 加到 1000 的总和——纯手动？

**循环** 就是解决这种"做同样的事很多遍"的工具。Python 提供两种：`for` 和 `while`。

## for + range：知道循环多少次时

最常用的写法：

```python
for i in range(5):
    print(i)
# 输出：0 1 2 3 4（每行一个）
```

逐字解读：

- `range(5)` 生成 0, 1, 2, 3, 4（**不包含 5**）
- `for i in ...` 把里面每个数轮流赋给 `i`
- **冒号** `:` 不能少；下面要 **缩进**（4 个空格）

`range` 的三种用法：

| 写法 | 等价于 |
|---|---|
| `range(5)`        | 0, 1, 2, 3, 4 |
| `range(1, 5)`     | 1, 2, 3, 4（左闭右开）|
| `range(1, 10, 2)` | 1, 3, 5, 7, 9（步长 2）|

## while：循环到条件不成立

```python
n = 5
while n > 0:
    print(n)
    n -= 1     # 等于 n = n - 1
# 输出：5 4 3 2 1（每行一个）
```

`while (条件)` 只要条件为真就一直循环。⚠️ **千万别忘了在循环体里改条件**——否则永远跑不出来（死循环），要按 Ctrl+C 强制终止。

## 累加：循环最经典的用法

求 1 到 100 的和：

```python
total = 0
for i in range(1, 101):     # 1, 2, ..., 100
    total += i              # 等于 total = total + i
print(total)   # 输出 5050
```

三步走：
1. 在循环外**先准备一个累加变量**（这里 `total = 0`）
2. 循环里**逐次加**到这个变量上
3. 循环外**输出**结果

**复合赋值** 是 Python 的常用简写：

| 写法 | 等价于 |
|---|---|
| `total += i` | `total = total + i` |
| `n -= 1`     | `n = n - 1` |
| `x *= 2`     | `x = x * 2` |
| `s += "abc"` | `s = s + "abc"` |

## break 和 continue

| 关键字 | 作用 |
|---|---|
| `break`    | **立即退出** 当前循环 |
| `continue` | **跳过本次** 循环剩余部分，进入下一次 |

```python
for i in range(1, 101):
    if i % 7 == 0:
        continue       # 7 的倍数不打印
    if i > 50:
        break          # 超过 50 退出
    print(i)
```

## 嵌套循环

循环里可以再放循环。九九乘法表的经典写法：

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}x{i}={i*j}", end=" ")
    print()    # 换行
```

外层循环跑一次，内层循环就把所有内层值都跑一遍。

## input + int 读输入

后面练习题会经常这么开头：

```python
n = int(input())   # 从键盘读一行，转成整数
```

`input()` 读到的是字符串（即使你输入数字）；用 `int()` 包一层把它变整数。如果输入有多个数空格分隔，下面这套组合最常见：

```python
parts = input().split()         # 按空格切成字符串列表
nums = [int(x) for x in parts]  # 每个转成整数
```

## 常见错误

1. **死循环**：`while True:` 或忘了改条件 → 程序永远跑
2. **range 边界搞错**：要打印 1 到 N，应该用 `range(1, N+1)`，不是 `range(1, N)`
3. **缩进错乱**：循环体的缩进必须一致，Python 比 C++ 严格
4. **累加变量没初始化**：`for i in ...: total += i` 之前没写 `total = 0` → NameError
5. **print 默认换行**：循环里的 `print(x)` 每个值占一行；想横向输出用 `print(x, end=" ")`
