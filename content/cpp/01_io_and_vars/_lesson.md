# 输入输出与变量

## C++ 是什么

C++ 是一门 **高性能的编译型语言**，几乎所有对速度敏感的软件都用它写——游戏引擎（Unreal、Unity 的核心）、操作系统（Windows 的大部分）、浏览器（Chrome、Firefox 的内核）、数据库（MySQL、MongoDB）、嵌入式设备（汽车、家电）。学好 C++ 你能理解"程序到底是怎么跑起来的"，因为它直接和内存、CPU 打交道，不像 Python 那样把细节藏在背后。

⚠️ 但 C++ 入门门槛比 Python 高。耐住性子先掌握"骨架"，后面会越学越顺。

## 一个能跑的最小程序

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

这五行就是 C++ 程序的"骨架"。逐行解释：

| 这一行                  | 干啥                              |
|---------------------|---------------------------------|
| `#include <iostream>` | 把输入输出工具引进来（cin、cout 都在这里）         |
| `using namespace std;`| 告诉编译器："std 这个命名空间下的东西，我直接用名字调"  |
| `int main() { ... }`   | 程序的入口；操作系统从 `main` 开始执行            |
| `cout << "..." << endl;` | 输出一行字（`endl` 是换行）              |
| `return 0;`            | 返回 0 给操作系统，表示"程序正常结束"         |

每一行末尾必须加 **分号** `;`（除了 `#include`、`using`、花括号这些）。漏一个分号编译器就会拒绝编译。

## cout 是输出，cin 是输入

`cout`（读作 see-out）把数据 **送出** 屏幕，方向用 `<<`（两个小于号）：

```cpp
cout << "答案是" << " " << 42 << endl;
```

`cin`（读作 see-in）从键盘 **读进** 数据，方向用 `>>`（两个大于号）：

```cpp
int a, b;
cin >> a >> b;
cout << a + b << endl;
```

记忆口诀：**箭头永远指向数据流去的方向**——cout 的箭头朝外，cin 的箭头朝里。

## 变量必须先声明类型

C++ 跟 Python 最大的区别：变量在使用前必须告诉编译器"它是什么类型"。

```cpp
int    age = 18;            // 整数
double price = 9.95;        // 小数（双精度）
char   grade = 'A';         // 单个字符（注意单引号）
string name = "小明";        // 字符串（需要 #include <string>）
bool   passed = true;       // 真假值
```

可以一行声明多个：

```cpp
int a, b, c;
int x = 1, y = 2;
```

## 编译执行的两步

写完源码 `main.cpp` 之后，要经过**两步**才能跑：

1. **编译**：`g++ main.cpp -o main.exe` 把源码翻译成可执行文件
2. **执行**：双击 `main.exe` 或在终端跑 `./main.exe`

我们这个练习平台已经替你把这两步都做好了，你只管写代码。点"提交运行"它就会调用 `g++` 编译并执行。

## 新手最常踩的坑

1. **忘了分号**：每条语句末尾的 `;` 漏一个，编译器会报一长串错误
2. **大小写错了**：`Cout` 和 `cout` 不一样；C++ 严格区分大小写
3. **`#include` 不全**：用了 `cout` 没写 `#include <iostream>`，编译报错
4. **忘了 `return 0;`**：不会让程序崩，但是好习惯——告诉别人"我正常结束"
5. **endl vs "\n"**：两者都能换行，`endl` 还会刷新缓冲区，速度稍慢；初学阶段不必纠结
